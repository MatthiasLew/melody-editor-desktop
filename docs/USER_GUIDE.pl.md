# Instrukcja użytkownika — Melody Editor Desktop

## 1. Start aplikacji

Po uruchomieniu aplikacji użytkownik widzi ekran menu. Z tego miejsca można utworzyć nowy projekt, wczytać zapisany projekt, przejść do ustawień, otworzyć pomoc albo zamknąć aplikację.

## 2. Tworzenie projektu

W ekranie **Nowy projekt** należy podać:

- nazwę projektu,
- tempo w BPM,
- liczbę taktów,
- zakres dźwięków.

Po zatwierdzeniu aplikacja otwiera ekran edytora melodii.

## 3. Edycja melodii

Kliknięcie pustego pola na siatce dodaje nutę. Pozycja pionowa oznacza wysokość dźwięku, a pozycja pozioma moment odtworzenia. Zaznaczoną nutę można przesuwać strzałkami. Nutę można usunąć klawiszem Delete albo prawym przyciskiem myszy.

## 4. Odtwarzanie

Przycisk **Odtwórz** uruchamia linię czasu. Program odtwarza nuty znajdujące się w aktualnym kroku. Pozycja startu pozwala rozpocząć odtwarzanie od wybranego miejsca. Opcja pętli powoduje powrót do pozycji startu po ostatniej nucie.

## 5. Zapis i eksport

Projekt można zapisać lokalnie w bibliotece aplikacji. Można go także wyeksportować do pliku JSON lub MIDI. Gotowe audio można wyeksportować do WAV albo MP3. Eksport MP3 wymaga FFmpeg.

## 6. Import

Aplikacja obsługuje import JSON i MIDI. Import MP3/WAV nie jest obsługiwany, ponieważ są to gotowe pliki audio, a nie edytowalne dane projektu.

## 7. Ustawienia

W ustawieniach można zmienić język, motyw, kontrast, wielkość tekstu, głośność oraz domyślne tempo nowych projektów. Zmiany wyglądu są widoczne od razu jako podgląd, ale zostają utrwalone dopiero po kliknięciu przycisku zapisu.
