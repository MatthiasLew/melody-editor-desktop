# User Guide — Melody Editor Desktop

## 1. Application start

After launching the application, the user sees the main menu. From this screen it is possible to create a new project, load an existing project, open settings, open help or close the application.

## 2. Creating a project

On the **New Project** screen, the user sets:

- project name,
- tempo in BPM,
- number of bars,
- pitch range.

After confirmation, the application opens the melody editor screen.

## 3. Melody editing

Clicking an empty grid cell adds a note. The vertical position represents pitch, while the horizontal position represents playback time. A selected note can be moved with arrow keys. A note can be deleted with the Delete key or with the right mouse button.

## 4. Playback

The **Play** button starts the timeline. The application plays notes placed on the current step. The start position allows playback to begin from a selected point. Loop mode returns playback to the start position after the last note.

## 5. Saving and exporting

Projects can be saved locally in the application library. They can also be exported to JSON or MIDI. Finished audio can be exported to WAV or MP3. MP3 export requires FFmpeg.

## 6. Import

The application supports JSON and MIDI import. MP3/WAV import is not supported because these are final audio files, not editable project data.

## 7. Settings

Settings allow the user to change language, theme, contrast, large text mode, volume and default tempo for new projects. Appearance changes are previewed immediately, but they are saved permanently only after pressing the save button.
